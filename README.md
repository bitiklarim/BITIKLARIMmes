# BITIKLARIMmes
Assalomu alaykum!  Men Ozod-Mashrab tahallusi bilan ijod qiluvchi havaskor shoirman. Hozirda talaba sifatida tahsil olaman va bo‘sh vaqtlarimni she'riyatga bag‘ishlayman.  "Ishq sharobini ichgan", deydilar. Bu gapda jon bor. Chunki she'rlarimning aksariyati qalb, muhabbat, sog‘inch va inson kechinmalaridan tug‘iladi.
